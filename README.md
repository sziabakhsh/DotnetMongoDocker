# .NET MongoDB Docker API

A production-style .NET 8 Minimal Web API built with MongoDB as the database and fully containerized using Docker.

This project demonstrates modern backend development practices including containerization, microservice-ready architecture, environment-based configuration, and API documentation using Swagger.

It is designed as a backend portfolio project showcasing cloud-ready and DevOps-friendly application structure.

---

## 🚀 Key Features

* .NET 8 Minimal Web API
* MongoDB integration (NoSQL database)
* Fully containerized with Docker
* Multi-stage Docker builds for optimized images
* Docker Compose for service orchestration
* Environment-based configuration (Development / Production)
* Swagger/OpenAPI for API documentation and testing
* Clean and scalable backend architecture

---
